# 一键式求职简历生成系统

就业指导课程期末考核 · 项目一（A 级 · 热门）

## 项目简介

用户填写信息后一键生成多种风格可下载的简历，支持模板切换与实时预览，内置简历评分建议。

## 功能要求

- [ ] 多模板简历生成（至少 3 套模板）
- [ ] 实时预览 + 在线编辑
- [ ] 导出 PDF / Markdown
- [ ] 简历评分与优化建议（STAR 法则）
- [ ] 支持中英文双语简历

## 推荐技术栈

React / Vue · TailwindCSS · jsPDF · Local Storage

## 就业知识点融入

研究"什么是好简历"（STAR 法则、关键词优化、ATS 适配），将知识转化为系统内置评分逻辑。
